# Ninth Tide — Development Instructions

Work ONLY in this repository. Do not access, edit, or reuse code, assets, history, or documents from Touchline or any other user project.

## Product direction
- Mobile-first portrait visual novel with original bold-outline, cel-shaded sprites, expressive poses, and sharp dialogue UI.
- Dark fantasy mystery about memory, identity, debt, and cycles.
- Preserve Mara, Elias, Vesper, the King, four lives, three impactful stats, branching routes, and nine endings.
- Use original art; do not copy copyrighted Ace Attorney sprites or Hitman voice performances.

## Engineering
- Build a responsive offline-capable PWA using maintainable HTML/CSS/JavaScript.
- Keep gameplay state deterministic and save data versioned.
- Respect reduced motion, muted-by-default sound, and keyboard/touch accessibility.
- Test navigation, save/load, all endings, and mobile viewports before merging.
- Do not publish publicly or deploy without approval.

## Immediate milestone
Import the prepared mobile development kit into this repository, verify the build, and open a PR for the next mobile visual-novel enhancement.
