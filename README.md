# Ninth Tide

A mobile-first dark fantasy visual novel set in a castle that rises from the sea every ninth tide.

## Project goals
- Original, bold cel-shaded anime-inspired character art and dramatic dialogue UI.
- Meaningful branching narrative with four lives, nine endings, relationships, and investigations.
- Responsive portrait-first PWA with offline support, save slots, and accessible touch controls.
- Browser voice narration and ambient audio with user-controlled playback.

## Current status
The mobile development kit and playable HTML preview have been prepared. The repository is being initialized separately from all other projects.

## Development
The game uses HTML, CSS, and JavaScript. Keep assets and source modular; avoid introducing dependencies without a clear reason.

## Privacy
This is a standalone project. Do not import, modify, or reference any code from Touchline or other repositories.
